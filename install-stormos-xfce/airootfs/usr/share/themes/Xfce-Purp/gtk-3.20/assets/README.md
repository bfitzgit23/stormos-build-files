# Xfce-Purp GTK3.20 Assets

This directory contains PNG button/entry/menu assets generated for the
GTK 3.20+ rendering path. They are generated by `generate_assets.py` in
the theme root.

## Why we need them

GTK 3.20 (`gtk-widgets.css`) historically uses `border-image` to draw
button/entry shapes. The `border-image` source URLs in `gtk-widgets.css`
reference these PNGs. We generate flat RGBA PNGs that match the CSS color
palette so buttons render consistently.

If you'd rather not use assets at all, replace every
`border-image-source: -gtk-scaled(url("assets/…"), url("assets/…@2"))`
line in `gtk-widgets.css` with `border-image-source: none` and the CSS
color rules will take over (recommended for newer GTK builds).

## Regeneration

From the Xfce-Purp directory:

    python3 generate_assets.py

Regenerated files overwrite the existing ones.
